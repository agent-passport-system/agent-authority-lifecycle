# Security Policy

This repository holds cases and test material, not deployed code. If a case, vector or example discloses a real vulnerability in a named system, report it privately instead of opening a public issue:

https://github.com/agent-passport-system/agent-authority-lifecycle/security/advisories/new

Issues in the Agent Passport System protocol or SDK belong at https://github.com/agent-passport-system/agent-passport-system/security/advisories.
